# Appearance

Open Settings and choose Light, Dark or System under Appearance. System follows the device's appearance while Locat is running, including when Settings is closed. Accent color offers Teal (default), Blue, Violet and Rose. Choices apply to login, chats, profiles and administration on this browser, and synchronize between its tabs.

Appearance choices are browser-local, shared by accounts using that browser, and excluded from chat/server backups. If browser storage prevents saving, the change still applies for the current session and Settings reports that it could not save. Unsupported saved values fall back to Dark and Teal. Themes do not change chat history or account data.

Device acceptance: choose each mode/accent, reopen Locat, check login and administration, open a second tab, and change the system theme while Settings is closed. Check text, message bubbles, focus rings, native selects and buttons in mobile Firefox and Chrome.
