# Hidden messages

Open a saved message's actions and choose **Hide on this device**. It disappears from the normal conversation and its search. Use **Hidden messages** above the chat header to browse or search hidden messages in that conversation. Open a message's actions there and choose **Restore message**.

The choice is saved per account in this browser. It does not delete the original content, change the recipient's copy, silence notifications or lock access. Pending messages cannot be hidden until delivery is confirmed. Edits and deletion controls still apply to hidden messages. Hidden content is excluded from the sidebar preview; another incoming message may produce a normal preview.

Chat backups retain message content but do not include hiding choices. Imports preserve existing local hiding choices. A fresh browser/device starts with visible messages. Clearing site data removes choices and local history. Read receipts sent before hiding are not withdrawn.

Acceptance: hide text and image messages, search the regular view, reopen the app, open Hidden messages and restore them. Verify edits/deletion from the sender still apply while hidden. Check another account has separate choices and encrypted backup export still retains the original history.
